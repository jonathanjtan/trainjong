# Faces of your own

Drop image files in here — png, jpg, webp, gif or svg — and they appear in the
lobby's face picker beside the drawn ones, cropped to the same circle. Folders
work too, one level deep, so a whole unzipped set can go in as it comes; the
first 240 are listed, in name order. The list is read off the disk, so a new
file shows up within a couple of seconds; no restart needed.

They are yours and they stay here: everything in this directory except this
file is gitignored, so nothing you drop in travels with the code. Whatever you
put on your own table is your business, but do not commit or publish art you do
not have the rights to.
